# 🐠 피쉬 키우기 (Fish Care Assistant)

물고기 사육에 필요한 모든 관리 작업을 자동으로 추적하고 알려주는 스마트 어시스턴트 앱입니다.

## 📋 문서 구조

이 프로젝트는 다음과 같은 문서로 구성되어 있습니다:

### 📄 [PRD.md](PRD.md) - Product Requirements Document
**제품 관점의 요구사항 명세서**
- 프로젝트 개요 및 비전
- 핵심 기능 및 부가 기능
- 타겟 사용자 (페르소나)
- 사용자 화면 설계 (UI/UX)
- 개발 로드맵
- 성공 지표 (KPI)

**대상 독자**: 제품 관리자, 기획자, 디자이너, 클라이언트

### 🔧 [TRD.md](TRD.md) - Technical Requirements Document
**기술 관점의 요구사항 명세서**
- 시스템 아키텍처
- 기술 스택 (Frontend, Backend, Database)
- 데이터베이스 설계 (ERD)
- API 명세
- 보안 요구사항
- 성능 요구사항
- 개발 환경 설정

**대상 독자**: 개발자, 데이터베이스 관리자, DevOps 엔지니어

---

## 🎯 프로젝트 개요

### 핵심 기능
1. **자동 일정 관리 및 알람** - 급이, 물 교환, 청소 일정을 설정하면 자동으로 알람
2. **물고기 정보 검색** - 물고기 이름을 검색하면 서식지, 먹이, 키우는 방법 등 정보 제공

### 부가 기능
- 다중 어항 관리
- 사육 기록
- 통계 및 분석
- 커뮤니티 기능 (향후)

### 타겟 사용자
물고기를 기르고 싶은데 관리 방법을 잘 몰라서 망설이는 **10~20대 청소년**

### 개발 플랫폼
- 웹사이트 (PC/모바일 반응형)
- PWA (Progressive Web App)
- (향후) 모바일 앱

## 📊 기술 스택 요약

### Frontend
- React 18+
- Material-UI / Chakra UI
- Redux Toolkit
- PWA (Service Worker)

### Backend
- Node.js + Express.js
- PostgreSQL
- Redis

### DevOps
- Docker & Docker Compose
- GitHub Actions (CI/CD)
- AWS EC2 / Google Cloud Run

### 알람 시스템
- 브라우저 푸시 알림 (Web Push API)
- 이메일 알림 (SendGrid)
- 인앱 알림 (Real-time)
